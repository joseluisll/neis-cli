Done — the MVP slice

  • • The predefined chain runs end to end on six verified addresses
  • • AI identifies selectors, capabilities and filters; results are stored and reused
  • • Filter criteria applied through the sites' own filters (ADDR-003..008) — e.g. EMA news 50 → 10 CHMP items

Core platform — complete

  • • Delivered (US-02..05, US-08, US-11): persistence over SQLite, address CRUD + validation, async execution and cron scheduling, chains of tasks, the content storage tree
  • • Chains: ordered 1..10 task lists with per-task parameters, run through the same executor lifecycle; a failing step records which step failed and what completed
  • • Content: deterministic per-address / per-capture / per-task tree, mirrored in the database; re-runs update in place
  • • Verified: 152 tests green; live runs leave step-by-step records and a well-ordered content tree

Then & later — the product

  • • Capabilities applied live: iterate pages, operate filters on the real sites
  • • The repository becomes the asset: dedup, export, search
  • • TUI and management UI make the system operable
