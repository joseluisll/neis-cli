NEIS — High-Level Architecture

News and Events Information System · from web pages of news & events to a structured, AI-assisted pipeline

What NEIS does

  • • Watches a catalog of web pages that list news and events
  • • Runs a chain of steps over each address: fetch, cleanse, understand, extract
  • • Applies a filter criterion through the site's own filter controls when the page offers them
  • • Produces structured news/events (title, date, link, description, source)

The capability idea

  • • Before acting on a page, NEIS learns what the page itself offers
  • • Pagination and filtering are detected and flagged onto the address
  • • Steps that need a capability only run when it is flagged — everything else is skipped, never guessed

Role of the AI

  • • Understands pages instead of hardcoded rules: what kind of page, where the list is, what filters exist
  • • Learnings are kept with the address — the AI is only needed the first time
  • • One shared assistant, one focused prompt per job
